# Dream

Reusable Human World Core and Human World Simulator backend, under
[epic #1](https://github.com/tushardhara/dream/issues/1) revision 3.

This is the #2 bootstrap, not a working simulator or API. All three commands
only show help and otherwise fail explicitly. No listeners, providers or database
connections are created. No scientific validity is claimed.

Run `make verify` with Git, Make, Python 3, Go 1.27.1 and a C compiler.
See [Contributing](CONTRIBUTING.md), [architecture](docs/adr/0001-backend-boundaries.md),
[requirements and gaps](docs/requirements.md), [pinned tools](docs/toolchain.md),
and [agent workflow](docs/agent-workflow.md).
